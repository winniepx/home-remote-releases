# Home Remote for Android

A local LG webOS remote for Android, with navigation, volume, touchpad, keyboard, TV apps and inputs. Application source is private; this repository contains signed downloads and update information.

**[Download HomeRemote.apk](https://github.com/winniepx/home-remote-releases/releases/latest/download/HomeRemote.apk)**

Requires Android 8 or newer. Open the download on your phone and confirm installation in Android. For an existing installation, update it without uninstalling. If Android blocks installation, review the permission for the browser or file manager you used.

Put the phone and TV on the same reachable home network, allow local network access, select your LG TV and confirm initial trust and pairing on the TV. Each phone pairs independently. Keep an existing TV control available for initial approval and recovery.

For future updates, open Home Remote → Settings → Updates → Check for updates. A new version offers release notes, download verification and an Install update button. Android may ask you to allow Home Remote as an installation source; return to the app and tap Install update again, then confirm the update in Android. Compatible signed updates retain app data. Never uninstall to bypass an update error.

TV control stays on the home LAN. Update checks and downloads contact GitHub only when requested. No app account, advertisements, tracking SDK, cloud relay or subscription is required. Keyboard, playback and audio support depend on the TV's active app and setup; wake depends on TV and network configuration.
